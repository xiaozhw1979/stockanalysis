一、公司概况

泡泡玛特成立于 2010 年，2020 年 12 月在香港联交所主板上市，是中国领先、全球扩张最快的潮流文化娱乐公司。公司围绕「IP 孵化与运营」构建了覆盖艺术家发掘、IP 运营、消费者触达（线下门店 + 机器人商店 + 线上渠道）与潮玩文化推广的全产业链平台。

核心商业模式为「自有/独家 IP + 盲盒等多品类商品化 + 全渠道直营零售」。旗下拥有 THE MONSTERS（LABUBU）、MOLLY、SKULLPANDA、CRYBABY、DIMOO、星星人 等头部 IP 矩阵。2025 年公司全球门店达 630 家（净增 109 家），机器人商店 2,637 台，业务覆盖中国、东南亚、东亚、北美、欧洲等市场。

四、股价表现与市场情绪

2025 年泡泡玛特股价随 LABUBU 全球爆红一路走高，52 周最高触及 339.80 港元。然而 2026 年 3 月 25 日年报发布当日，尽管业绩创纪录，股价单日重挫 约 22.5%，随后公司火线回购约 5.99 亿港元股份以稳定信心。当前股价 178.30 港元，较 52 周高点回撤约 47.5%。

五、SWOT 分析

优势 Strengths

  • LABUBU 成为现象级全球 IP，品牌出圈进入主流消费文化
  • IP 矩阵纵深：6 大 IP 营收破 20 亿、17 个 IP 破亿，非单一依赖
  • 毛利率约 70%，直营体系 + 高 IP 溢价带来强盈利能力与现金流
  • 全渠道运营能力（门店/机器人商店/线上/会员体系）行业领先

劣势 Weaknesses

  • 单一 IP 集中度高：THE MONSTERS 占收入 38.1%，潮流退坡风险大
  • 潮玩缺乏内容护城河（对比迪士尼/三丽鸥的影视与故事支撑）
  • 盲盒模式受政策与舆论监管约束，未成年人销售监管趋严
  • 二级市场炒作价格回落可能反噬一级市场购买热情

机会 Opportunities

  • 欧美市场渗透率仍低，海外门店扩张空间广阔
  • 品类扩张：积木、首饰（popop）、主题乐园、动画内容多元变现
  • IP 授权与联名（奢侈品牌、影视、游戏）打开轻资产收入
  • 公司提出向「千亿收入」的世界级 IP 集团迈进

威胁 Threats

  • 潮玩赛道竞争加剧（名创优品 TOP TOY、52TOYS、卡牌类玩家）
  • 仿冒品（"Lafufu"）泛滥侵蚀品牌与海外定价体系
  • 全球消费景气波动、关税与地缘政治影响海外供应链
  • 潮流消费天然周期性，热度退潮时业绩与估值双杀风险

六、估值与投资结论

估值水平

以 2025 年经调整净利润 130.8 亿元（约合 143 亿港元）和当前约 2,400 亿港元市值估算，静态市盈率约 17 倍；若 2026 年盈利增长 20–30%，对应动态市盈率约 13–14 倍。相较 2025 年中超过 60 倍的峰值估值，泡沫已大幅出清，当前估值开始计入「增速回落 + IP 依赖」的悲观预期。

结论

核心判断：泡泡玛特已从「中国盲盒公司」蜕变为具备全球影响力的 IP 消费集团，2025 年业绩验证了其商业模式的爆发力；但市场定价的焦点已从「有多快」转向「能多久」。股价自高点近腰斩后，估值风险已显著释放，中长期配置价值开始显现，关键跟踪变量为：① LABUBU 之后第二个现象级 IP 能否接棒（关注 CRYBABY、星星人）；② 海外（尤其欧美）同店与开店进度；③ 季度营收增速是否企稳于 20% 以上。

风险提示：若 LABUBU 销售明显退坡且无新 IP 接力，盈利与估值可能继续双向下修；短期股价波动剧烈，不适合低风险偏好投资者。
